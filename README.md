# Social-Media-Mental-Health-PowerBI

# 📊 Impact of Social Media on Mental Health and User Behaviour

## 📌 Project Overview
This Power BI dashboard analyzes the impact of social media usage on mental health and user behaviour. It provides interactive insights into screen time, anxiety levels, depression scores, sleep patterns, and platform usage.

## 📂 Dataset
- Source: Social Media Mental Health Dataset
- Data includes:
  - Age, Gender
  - Daily Screen Time
  - Sleep Duration
  - Anxiety Score
  - Depression Score
  - Social Media Platforms
  - Content Type
  - User Archetypes

## 🎯 Objectives
- Analyze how social media usage affects mental health
- Identify patterns between screen time and sleep
- Compare anxiety and depression across platforms
- Understand user behaviour using segmentation

## 📊 Key Features
- Interactive filters (Platform, Gender)
- KPI Cards:
  - Avg Sleep Hours
  - Avg Anxiety Score
  - Avg Screen Time
  - Avg Depression Score
- User Archetype Analysis
- Platform-wise User Distribution
- GAD-7 Severity Analysis
- Content Type vs Anxiety Comparison

## 📈 Key Insights
- Increased screen time is linked with higher anxiety and depression scores
- Users with severe GAD-7 levels have the highest screen time
- Self-help and lifestyle content show higher anxiety levels
- Female users tend to have slightly higher anxiety scores
- Platform usage patterns vary significantly across age groups

## 🛠️ Tools Used
- Power BI
- DAX
- Visualization

## 🚀 Conclusion
This dashboard highlights the relationship between social media usage and mental health, helping identify key behavioural patterns and risk factors.
